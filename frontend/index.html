Adaptive Hybrid Quantum-Classical CNN

Pneumonia detection from chest X-ray images using a MobileNet backbone fused with a variational quantum layer and adaptive fusion gate.

Hybrid AI Quantum Simulator FastAPI + Web UI

About this system

The model extracts visual features using a lightweight CNN, projects them to a compact latent space, and processes those features in both classical and quantum branches. An adaptive gate learns how much each branch should influence the final decision.

  • Dataset: Kermany chest_xray (NORMAL vs PNEUMONIA)
  • Target: Binary classification
  • Backend API: FastAPI with realtime prediction endpoint
  • Frontend: upload preview, prediction breakdown, confidence report

How the pipeline works

01

X-ray image is resized and normalized to match ImageNet preprocessing.

02

MobileNetV3 extracts visual representations from lung regions.

03

Reduced latent vector is encoded into a quantum circuit with rotational gates and entanglement.

04

Adaptive gate fuses quantum and classical logits into final NORMAL/PNEUMONIA prediction.
